# Modelagem de Banco de Dados para Oficina Mecânica

## Sobre o projeto

Este projeto apresenta a modelagem de um banco de dados relacional para o gerenciamento de uma oficina mecânica, desenvolvido no MySQL Workbench.

O modelo foi estruturado para organizar informações de clientes, veículos, mecânicos, equipes de trabalho e ordens de serviço, permitindo acompanhar os processos de manutenção e revisão de veículos.

## Estrutura do banco de dados

A modelagem utiliza nove tabelas relacionadas por chaves primárias e estrangeiras, representando o fluxo operacional da oficina.

As ordens de serviço concentram informações sobre os veículos, equipes responsáveis, serviços, peças, valores, prazos e status de execução.

## Tecnologias utilizadas

- MySQL Workbench
- Modelagem Entidade-Relacionamento (MER)
- Banco de Dados Relacional
- GitHub

## Considerações finais

O projeto demonstra a aplicação de conceitos de modelagem de dados, definição de entidades, relacionamentos e regras de negócio.

A estrutura proposta permite organizar e acompanhar as atividades de uma oficina mecânica, servindo como base para o desenvolvimento de um sistema de gerenciamento de ordens de serviço.
